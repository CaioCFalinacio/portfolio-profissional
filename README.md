# Portfólio Profissional | Caio Falinacio

Website de portfólio profissional responsivo, desenvolvido para a disciplina de **Laboratório de Desenvolvimento de Software** da **PUC Minas**.

---

## 🚀 Funcionalidades Principais

- **Sobre Mim / Hero**: Apresentação profissional com resumo bio e botões de ação.
- **Projetos**: Linha do tempo interativa exibindo os projetos acadêmicos e pessoais com tecnologias utilizadas.
- **Experiências**: Cards detalhados sobre atuação profissional e formação acadêmica.
- **Contato**: Seção dedicada com e-mail direto, WhatsApp, LinkedIn e links para GitHub pessoal e acadêmico.
- **Internacionalização (PT/EN)**: Suporte completo a alternância de idiomas em tempo real (Português e Inglês).
- **Design Responsivo**: Layout otimizado para dispositivos móveis, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica)
- **CSS3** (Variáveis CSS, Flexbox, Grid e Responsividade)
- **JavaScript (Vanilla ES6+)** (Alternância de idiomas, navegação suave e interatividade)
- **Lucide Icons** (Ícones modernos)

---

## 📁 Estrutura de Diretórios

```text
portfolio-profissional/
├── assets/
│   ├── css/
│   │   └── style.css            # Estilos globais e responsividade
│   ├── images/                  # Fotos de perfil e assets visuais
│   └── js/
│       └── main.js              # Lógica do site e dicionário PT/EN
├── index.html                   # Página principal do portfólio
└── README.md                    # Documentação do projeto
```

---

## ⚙️ Executando Localmente

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web ou utilize uma extensão de servidor local, como a **Live Server** no VS Code.
